Semester 1

Course Title Description
CMPE111 Introduction to Computer Engineering This course provides an overview of computer engineering, covering the fundamental concepts, historical development, and the role of computer engineers in designing and developing computer systems.
CMPE112 Digital Logic Design This course introduces the principles of digital logic design, including Boolean algebra, logic gates, combinational and sequential circuits. Students learn how to design and analyze digital systems.
CMPE113 Computer Organization and Architecture This course focuses on the organization and architecture of computer systems. Topics include instruction set architecture, processor design, memory hierarchy, input/output systems, and performance evaluation.
CMPE114 Programming Fundamentals This course covers the basics of programming, including algorithmic problem-solving, programming languages, control structures, data types, functions, and modular programming techniques.
CMPE115 Data Structures and Algorithms This course explores data structures (such as arrays, linked lists, trees, graphs) and algorithm design techniques. Students learn how to analyze, implement, and use efficient algorithms to solve computational problems.

Semester 2

Course Title Description
CMPE121 Electronic Circuits This course introduces the principles of electronic circuits, covering topics like analog and digital circuit analysis, semiconductor devices, operational amplifiers, and basic electronic components.
CMPE122 Signals and Systems This course explores the theory and applications of signals and systems. Students learn about continuous and discrete-time signals, Fourier analysis, system properties, and signal processing techniques.
CMPE123 Microprocessors and Microcontrollers This course focuses on the architecture, programming, and interfacing of microprocessors and microcontrollers. Topics include assembly language programming, memory systems, input/output, and embedded systems.
CMPE124 Computer Networks This course covers the fundamentals of computer networks, including network protocols, architecture, routing, switching, and network security. Students learn how data is transmitted and exchanged between networked devices.
CMPE125 Operating Systems This course explores the principles and components of operating systems. Topics include process management, memory management, file systems, device management, and concurrency control.

Semester 3

Course Title Description
CMPE211 Computer Hardware Design This course focuses on the design and implementation of computer hardware components, including digital circuitry, processor architecture, memory systems, and input/output interfaces.
CMPE212 Software Engineering This course introduces software engineering principles and practices. Students learn about the software development life cycle, requirements engineering, software design, testing, and project management.
CMPE213 Database Systems This course covers the design, implementation, and management of database systems. Topics include data modeling, relational databases, SQL, database administration, and data integrity.
CMPE214 Computer Graphics This course introduces the fundamentals of computer graphics, including 2D and 3D transformations, rendering techniques, graphical user interfaces, and computer animation.
CMPE215 Introduction to Artificial Intelligence This course provides an introduction to the field of artificial intelligence. Topics may include problem-solving, knowledge representation, search algorithms, machine learning, and natural language processing.

Semester 4

Course Title Description
CMPE221 Digital Systems Design This course focuses on the design and implementation of digital systems using hardware description languages. Students learn about FPGA (Field-Programmable Gate Array) design, synthesis, and testing.
CMPE222 Embedded Systems This course explores the design and programming of embedded systems, which are computer systems embedded within other devices. Topics may include real-time operating systems, interfacing, and system integration.
CMPE223 Communication Systems This course covers the principles of communication systems, including analog and digital modulation, multiplexing, coding, error detection and correction, and wireless communication.
CMPE224 VLSI Design This course focuses on the design and implementation of Very Large Scale Integration (VLSI) circuits and systems. Topics include transistor-level design, logic synthesis, and physical design techniques.
CMPE225 Computer Architecture This course explores advanced computer architecture concepts, including pipelining, cache memory, parallel processing, and performance evaluation. Students gain a deeper understanding of the internal workings of computer systems.

Semester 5

Course Title Description
CMPE311 Advanced Data Structures and Algorithms This course delves into advanced data structures and algorithm design techniques. Students explore topics such as advanced tree structures, graph algorithms, algorithmic analysis, and algorithm optimization.
CMPE312 Computer Security This course focuses on the principles and techniques of computer security. Students learn about cryptography, network security, access control, security policies, and ethical considerations in securing computer systems.
CMPE313 Distributed Systems This course covers the design and implementation of distributed systems, which involve multiple interconnected computers. Topics may include distributed algorithms, fault tolerance, synchronization, and distributed file systems.
CMPE314 Web Development This course introduces web development concepts and technologies. Students learn about client-side and server-side programming, web design principles, web frameworks, and database integration for creating dynamic web applications.
CMPE315 Introduction to Machine Learning This course provides an introduction to machine learning algorithms and techniques. Students learn about supervised and unsupervised learning, model training and evaluation, feature selection, and applications of machine learning.

Semester 6

Course Title Description
CMPE321 Real-Time Systems This course focuses on the design and analysis of real-time systems, which require timely responses to external events. Students learn about real-time operating systems, scheduling algorithms, and real-time constraints.
CMPE322 Robotics This course explores the principles and applications of robotics. Students learn about robot kinematics, dynamics, control systems, sensors, and algorithms for autonomous robot navigation and manipulation.
CMPE323 Wireless Networks This course covers the design and implementation of wireless networks. Students study wireless communication principles, network protocols, medium access control, wireless security, and emerging wireless technologies.
CMPE324 Digital Signal Processing This course focuses on the theory and applications of digital signal processing techniques. Students learn about signal analysis, filtering, transformation, spectral analysis, and digital audio/image processing.
CMPE325 Software Development Practices This course explores software development methodologies and practices. Students learn about software engineering processes, software testing, debugging, version control, and software project management techniques.

Semester 7

Course Title Description
CMPE411 Computer Vision This course focuses on the theory and applications of computer vision. Students learn about image processing, feature extraction, object recognition, 3D vision, and applications in areas such as robotics, healthcare, and surveillance.
CMPE412 Cloud Computing This course covers the principles and technologies of cloud computing. Students learn about virtualization, cloud infrastructure, service models (IaaS, PaaS, SaaS), cloud security, and deployment considerations for scalable and flexible computing.
CMPE413 Big Data Analytics This course explores the techniques and tools for analyzing large-scale datasets. Students learn about data preprocessing, data mining algorithms, distributed computing for big data, and data visualization.
CMPE414 Mobile Application Development This course focuses on the development of mobile applications for smartphones and tablets. Students learn about mobile app frameworks, user interface design, mobile databases, and app deployment considerations.
CMPE415 Natural Language Processing This course covers the theory and techniques for processing and analyzing natural language data. Students explore topics such as text classification, sentiment analysis, language modeling, and machine translation.

Semester 8

Course Title Description
CMPE421 Network Security This course delves into advanced topics in network security. Students learn about secure network protocols, intrusion detection and prevention, network forensics, and security measures for protecting networks from cyber threats.
CMPE422 Internet of Things (IoT) This course explores the concepts and applications of the Internet of Things (IoT). Students learn about IoT architectures, sensor networks, IoT protocols, data analytics for IoT, and IoT security considerations.
CMPE423 High-Performance Computing This course focuses on the principles and techniques for high-performance computing. Students learn about parallel computing architectures, parallel algorithms, distributed computing, and performance optimization strategies.
CMPE424 Compiler Design This course covers the design and implementation of compilers, which translate high-level programming languages into machine code. Students learn about lexical analysis, syntax parsing, semantic analysis, code optimization, and code generation.
CMPE425 Human-Computer Interaction
